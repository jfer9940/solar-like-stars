# A Targeted search for radio flares on solar-like stars: Code repository

Attached is the code written and used during this project. Brief descriptions of all notebooks and scripts are outlined below, although code has been commented for clarity. Many scripts are similar, as tasks like downloading additional data or making extra plots needed to be done for a small sample of stars. The code uploaded here includes additional details and notebooks that were not used for the thesis. Feel free to check them out anyway and see some of the dead ends we ran into :) 

Please note that there may be some package version conflicts. Some of this code was run locally on a Windows machine, while much of it was run remotely on a Linux machine. All personal information has also been removed.
